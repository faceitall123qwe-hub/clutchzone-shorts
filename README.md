# clutchzone-shorts

Promo shorts for my game [Clutchzone](https://github.com/faceitall123qwe-hub/clutchzone). The
gameplay is recorded frame by frame from the game (so it plays at a smooth 60 fps even on a slow
laptop) and then edited here in HyperFrames: captions, cuts, music.

```bash
node scripts/build.mjs clutch   # or arsenal / laptop
npx hyperframes render --fps 60
```
